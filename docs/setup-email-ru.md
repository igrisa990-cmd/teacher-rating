# Запуск регистрации по email

Сайт: https://teacher-rating-iota.vercel.app/

Отправитель первого запуска: `gnavi00@mail.ru`.

## 1. Создать пароль для отправки писем

Открой свою почту Mail.ru → Настройки → Все настройки → Безопасность → Пароли для внешних приложений.

Создай пароль с названием `Учитель+ Supabase` и правом **«Только отправка писем в Почте»**. Основной пароль от почты не подходит. Создание и ввод пароля выполняешь ты; пароль не нужно отправлять в чат или сохранять в проекте.

[Официальная инструкция Mail.ru](https://help.mail.ru/mail/login/mailer/).

## 2. Настроить Supabase

Открой [SMTP-настройки проекта](https://supabase.com/dashboard/project/jjzjmwvnhxwwxlyeeciz/auth/smtp), войди в свой аккаунт и включи Custom SMTP.

| Поле | Значение |
| --- | --- |
| Sender email | `gnavi00@mail.ru` |
| Sender name | `Учитель+` |
| Host | `smtp.mail.ru` |
| Port | `465` |
| Username | `gnavi00@mail.ru` |
| Password | Пароль приложения из шага 1 |

Сохрани настройки. Порт 465 использует SSL/TLS. Не отключай проверку почты для обхода ошибок доставки.

## 3. Указать адрес сайта

В [URL Configuration](https://supabase.com/dashboard/project/jjzjmwvnhxwwxlyeeciz/auth/url-configuration):

- Site URL: `https://teacher-rating-iota.vercel.app`
- Redirect URLs: добавь `https://teacher-rating-iota.vercel.app/`

В Email Provider оставь **Confirm Email включённым**. Ссылки из писем подтверждения и восстановления должны возвращать на этот сайт. Подготовленные русские шаблоны находятся в `supabase/templates/confirmation.html` и `supabase/templates/recovery.html`; вставить их можно в соответствующие Email Templates, сохранив `{{ .ConfirmationURL }}`.

## 4. Проверить запуск

Зарегистрируй новый email, к которому у тебя есть доступ. Открой письмо подтверждения, затем войди на сайт. Измени имя, регион и тему, перезагрузи страницу и проверь сохранение. Затем проверь «Не помню пароль» и переход из письма восстановления.

До этого теста отправка писем считается непроверенной. Если появляется `email_address_not_authorized`, обычно ещё используется встроенный почтовый сервис Supabase, ограниченный адресами команды проекта. [Документация Supabase SMTP](https://supabase.com/docs/guides/auth/auth-smtp).

Обычный почтовый ящик используется для первого запуска. Перед значительным ростом регистраций стоит перейти на отдельный сервис транзакционных писем и свой домен отправки.

SMS отложены по твоему решению и не включены.
