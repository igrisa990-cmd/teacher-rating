# Linked staff profiles and vertical roster tables

The live catalog gained 2,256 teachers across 169 schools in 33 regions. It now contains 42,199 active schools and 82,115 active teachers; 3,539 schools have teacher profiles. No school, authentication or database-schema changes were needed for these two imports.

Staff parser version 9 recognizes one-person vertical tables only when the same table owns exactly one explicitly labeled full name and classroom position, with at most one discipline field. Nested tables, repeated names/positions, ambiguous disciplines and qualification-only roles are rejected. Responsive Gosweb profiles may repeat a name and position for mobile and desktop headers; the reader accepts exactly one dedicated top/content pair only when both agree. Explicit discipline lists stay separate from education and biographies.

The collector follows only published, named, same-origin Gosweb staff-profile links, including those on the verified home/identity pages. Generic footer labels cannot overwrite a named profile link. Existing DNS, TLS, robots, identity checks and finite page budgets remain enforced. Each selected subject retains a single source URL/hash; richer explicit fields replace weaker summaries, and conflicting explicit disciplines for the same identity are held rather than combined across pages.
