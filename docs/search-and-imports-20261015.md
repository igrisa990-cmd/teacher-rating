# Поиск, настройки и продолжение импорта — 15 октября 2026

Опубликованный каталог: **41 661 школа, 33 138 учителей в 1 577 школах**. В этом обновлении добавлено 4 672 учителя, уточнены метаданные 24 школ. Отзывы и оценки новых записей равны нулю; существующие профили и пользовательские правки сохранены.

## Интерфейс

Поиск стал компактнее: строка запроса, регион и кнопка «Найти» расположены рядом. В меню региона есть поиск по названию и сокращениям, клавиши вверх/вниз, Enter и Escape, «Мой регион» и «Вся Россия». Изменение области поиска сохраняет запрос и очищает населённый пункт; личный регион аккаунта оно не меняет. Город или село выбирается дополнительно. На телефоне поля складываются в одну колонку, кнопки шапки остаются в одной строке.

Верхняя кнопка «Настройки» открывает отдельную страницу с вкладками «Оформление», «Панель», «Регион» и, после входа, «Аккаунт». Панель можно отключать и выбирать её разделы. Верхняя кнопка настроек доступна и при отключённой панели. Прежние темы и сохранение предпочтений используются без смены формата данных.

Гостю один раз предлагается регистрация; закрытие или «Пока без аккаунта» сохраняется только на этом устройстве. Каталог остаётся доступен. Регистрация по email использует существующий Supabase Auth: выбор региона показывается после подтверждённого входа в новый аккаунт. Регион впоследствии можно изменить кнопкой в профиле или в настройках. Восстановление пароля не прерывается предложением регистрации. Реальные тестовые аккаунты, письма и SMS для проверки этого обновления не создавались и не отправлялись; доставка подтверждений зависит от текущих настроек почты проекта.

Новых ОГРН относительно предыдущего полного набора нет, изменены 24 записи метаданных. Прежние ID, названия, основные адреса, отзывы и архивный статус автоматически не заменяются. Неразрешённые адреса и филиалы сохраняются для отдельной работы.

После полного предыдущего прохода по 23 603 сайтам повторно проверены все 2 202 сайта с подтверждённой организационной принадлежностью, но ранее не извлечённым HTML-составом. 219 сайтов вернули состав; после проверки действующей общей лицензии и профессионального содержания допущено 4 672 записи из 218 школ. Все они связались с существующими активными школами, неоднозначных имён при импорте нет. Составы других школ из предыдущего прохода сохранены со своими прежними датами проверки; эти записи не выдаются за повторно проверенные сегодня.

Совокупный файл источников содержит 33 102 учителя из 1 576 школ; прежние 36 учителей гимназии в Балашихе дают итоговые 33 138. Предмет не опубликован у 13 656 записей совокупного набора: поле источника остаётся пустым. Контакты, фотографии, личные биографии и оценки не импортируются. Пять записей исключены проверкой содержания, включая три из прошлого набора.

**Это не полный кадровый реестр всех учителей России.** Совокупный отчёт содержит 22 027 сайтов для дальнейшего исследования: доступность, идентичность, запреты доступа, документы и неподдерживаемая разметка. Общедоступный документ со списком сотрудников не считается разобранным, если его формат пока не поддерживается. Ограничения robots.txt, TLS и CAPTCHA не обходятся. Учёт всех записей выгрузки лицензий не равен учёту всех зданий, филиалов и педагогов.

## Воспроизведение

Полные снимки, изменения и SHA256 находятся в локальной рабочей папке `data/registry/20261015-*`. Новые полные наборы учителей и архив ссылок для проверки исключены из Git: публикация репозитория содержит код и агрегированные отчёты, база сайта уже обновлена. Наборы изменений применены существующими закрытыми функциями под ключами `20261015-license-changes` и `20261015-staff-changes`; новые права доступа и миграции для этого обновления не потребовались.

1. Потоково извлечь ZIP: `python scripts/extract-license-archive.py --archive work/license-russia-full-20261014.zip --out work/license-xml-20261014` (lxml).
2. Подготовить лицензии: `node scripts/prepare-license-snapshot.cjs --input work/license-xml-20261014/active-general.ndjson --root work/license-xml-20261014 --output data/registry/20261015-licensed-schools --download-report work/license-russia-full-20261014.zip.json --extended-localities`. JSON скачивания содержит проверенные `source`, `bytes`, `sha256`, `downloadedAt`.
3. Возобновляемая повторная проверка: `node scripts/retry-staff-formats.cjs --previous-root work/national-staff-20261014 --root work/national-staff-20261015 --workers 24`. Исходные проверенные контрольные файлы сохраняются, новый проход соблюдает те же сетевые ограничения.
4. Сформировать составы: `node scripts/prepare-national-staff.cjs --root work/national-staff-20261015 --output data/registry/20261015-national-staff --license-input work/license-xml-20261014/active-general.ndjson`.
5. `scripts/catalog-snapshot-diff.cjs` сравнивает полный текущий снимок с предыдущим (для лицензий допускается список прежних gzip через запятую). Учитываются содержательные поля, а не только время проверки. Выход — отдельный NDJSON gzip и отчёт.
6. `node scripts/stage-catalog-snapshot.cjs license|staff data/registry/ИМЯ.ndjson.gz ИМЯ-ЗАПУСКА` проверяет контрольные суммы и количество, создаёт SQL-пакеты без сетевой записи. Применить их административным соединением, затем `999-apply.sql`. Браузеру доступны только опубликованные карточки под прежним RLS.

Проверки: `search-experience.test.cjs`, `region-runtime.test.cjs`, `account-center.test.cjs`, `catalog-search.test.cjs`, `catalog-provenance.test.cjs`, `national-staff.test.cjs`, `registry.test.cjs`; сверка рабочей базы по связям и нулевым оценкам новых записей. В браузере проверены отказ от регистрации, регион по сокращению, смена области поиска, вкладки настроек, мобильная шапка и выключение/включение панели с восстановлением исходного состояния.
