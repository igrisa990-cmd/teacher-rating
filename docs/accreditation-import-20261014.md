# Полная выгрузка аккредитации и выбор региона

14 октября 2026 года загружено 34 235 новых организаций. Активный каталог вырос с 5 103 до **39 338 школ**. 103 карточки с карты получили ОГРН при однозначном совпадении адреса или названия в одном населённом пункте; всего у 1 070 существующих карточек дополнены сведения об аккредитации. Учителей по-прежнему 36: данный реестр не содержит состава сотрудников.

Источник: [официальные открытые данные Рособрнадзора](https://isga.obrnadzor.gov.ru/accredreestr/opendata). Архив от 13 октября: 351 788 599 байт, SHA256 `8cdba61603e551428b21fdbafe22b8f5cd7264b2881f3d574dc18721ed346664`. Электронная подпись архива отдельно не проверялась. XML прочитан полностью: 107 426 свидетельств, 43 467 действующих, 38 552 с действующими программами общего образования. После проверки ОГРН, адреса, типа организации и устранения повторных свидетельств подготовлено 35 305 организаций из 89 региональных категорий источника. Подробные исключения и контрольные суммы находятся в `data/registry/20261013-accredited-schools-report.json`.

Полный обход источника не означает полный перечень всех лицензированных школ, зданий, филиалов или учителей. Адреса без однозначного населённого пункта и спорные записи исключены. Школы без аккредитации требуют сверки с реестром лицензий. Возможные совпадения картографических карточек, которые не удалось подтвердить, автоматически не объединяются. Названия и территориальные категории сохранены согласно источнику.

## Воспроизведение

1. `scripts/extract-accreditation.py` читает XML прямо из ZIP потоково, с отключёнными DTD, сетью и раскрытием сущностей. Временные материалы находятся в игнорируемой папке `work/`.
2. `scripts/prepare-accreditation.cjs` проверяет текущие общие программы, статус, ОГРН и адрес, объединяет свидетельства по ОГРН, создаёт gzip и отчёт. Телефоны, email и данные сотрудников в публикуемый набор не входят.
3. `node scripts/stage-accreditation.cjs` проверяет контрольные суммы и создаёт последовательные SQL-пакеты в `work/accreditation-stage`. Выполнить их административным соединением, затем `999-apply.sql`. Скрипт не содержит ключей и не пишет в сеть.
4. Закрытая функция `private.apply_accreditation_snapshot` проверяет полноту промежуточной таблицы, использует блокировку импорта, сохраняет существующие ID, правки, отзывы и состояние архива. Повторное применение не создаёт новые записи. Первый рабочий импорт зарегистрирован как `20261013-accreditation`; повтор с другим именем того же набора также объединяется по ОГРН.

Публичные функции `catalog_stats`, `catalog_bootstrap`, `catalog_localities` работают с правами вызывающего и RLS. Стартовая выдача ограничена 200 школами и 120 учителями плюс школами этих учителей; поиск работает по всему каталогу. Прямые ссылки, избранное и школа профиля догружаются по ID, сотрудники — отдельно для открываемой школы.

Регион предлагается после первого входа в подтверждённый новый аккаунт. Есть поиск по названию и сокращениям, клавиатурное управление и пропуск. Флаг однократного показа и регион хранятся в личных настройках. Последующая смена доступна в разделе «Настройки». Каталог предлагает поиск в своём регионе или по всей базе, не меняя личный регион. Поле региона в заявке школы описывает её адрес и сохранено.

## Проверки

Node: `tests/accreditation.test.cjs`, `tests/region-runtime.test.cjs`, существующие проверки аккаунта, поиска, школьных разделов, источников и реальной авторизации. PGlite: `tests/accreditation-sql.cjs` — сохранение ID/правок/архива, точное объединение, повторный импорт, ограниченная загрузка, глобальные счётчики, поиск населённых пунктов, закрытый импорт.

Проверки Supabase не выявили ошибок уровня ERROR. Служебные таблицы имеют RLS без публичных политик — намеренный запрет доступа ([описание](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy)). Остались прежние предупреждения о вызываемых SECURITY DEFINER функциях, политиках и индексах ([функции](https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable), [RLS](https://supabase.com/docs/guides/database/postgres/row-level-security#call-functions-with-select)). Новые публичные функции используют SECURITY INVOKER, импорт недоступен клиентским ролям. Настройка SMTP и реальная доставка регистрационного письма этим изменением не подтверждены.
