# Public teacher catalog expansion — 19 October

The first two verified import phases added **41,785 teachers**, raising the public catalog from 83,636 to **125,421 active teacher profiles**. There are 42,199 active school profiles and 5,804 schools with teachers. The database retains 214 teacher rows belonging to archived schools; those are excluded from the active catalog. This report describes these completed phases while a separate government-platform source queue continues.

Twelve guarded runs `20261018-staff-fullremaining-01..12` initially inserted 22,982 rows. A contextual recheck then excluded eight historical or ambiguous entries: four from a 2025 summer-camp table, three from a 2015–2016 training report, and one from a table that mixed role and education fields. Exact backups and source proofs were retained locally; none had reviews or pending teacher requests. The corrected first phase therefore contributed 22,974 profiles. Ten subsequent runs `20261019-staff-additional-01..10` added another 18,811 profiles from independently audited source cohorts. No existing canonical personnel fields were refreshed or combined across sources.

The additional phase re-read 83,093 candidate source records: 57,276 from earlier completed public-site checkpoints, 22,053 from the remaining non-government websites, 3,606 from newly verified government-platform websites, 138 from other checksum-proven cached pages and 20 from seven current-year official PDFs. Existing identities and overlaps were removed before staging. Exact original response checksums, school-owned source paths, explicit classroom roles and the current licensed organization identity were verified independently. The latest explicitly listed license snapshot was 18 October; its active organization set matched the prior day. A professional listing alone does not guarantee present employment.

Parser version 12 accepts a classroom position only when it belongs to the same name or row. Diploma, training and neighboring-person fields cannot supply teaching subjects. Incidental plain tables on identity pages are excluded; explicit school-owned staff components remain eligible. Shared portals retain school-path boundaries. Missing subjects stay empty. Original source check times are preserved when re-reading caches. Bounded gzip and lossless legacy-encoding recovery require an exact match to the original response checksum. PDF names and fields were re-extracted independently from the seven saved binary sources.

Network collection uses strict DNS, public-address, TLS and robots checks. The remaining 1,077 deferred government-platform sites are being processed by one queue with a global 500 ms request interval. A circuit breaker records explicit deferrals after repeated network failures or rate limiting. A processed checkpoint inventory does not prove that every URL was fetched or every roster is complete. Unsupported formats, access restrictions, ambiguous identities, partial rosters and unpublished lists remain review work; national coverage is incomplete.

The active local canonical source now has 125,385 rows, SHA256 `6fa54e11a0e965e47486423842ca7f48ac63b47b3b2dd0e7c533721ca45990fb`. All 106,574 preceding source objects remain unchanged. The 36-row difference between canonical source identities and active catalog profiles reflects separately maintained records.

Post-import checks matched all 18,811 additional staged rows and found zero source-field mismatches, imported ratings/reviews, orphan teachers or duplicate active school organization numbers. Each guarded transaction checked its expected counts and payload checksum, prevented replay and protected pre-existing teacher fields.

Mobile verification at 375 pixels found a new teacher using a lowercase partial name, opened the profile and followed the correct school link. An intermittent startup timeout was traced to the catalog bootstrap query. Migration `20261019162706_catalog_bootstrap_point_lookups.sql` hydrates only the bounded candidate IDs through primary-key lookups while preserving caller RLS and the response format. The public Moscow bootstrap measurement improved from 4,988 ms to 941 ms. Local PostgreSQL tests verify school/teacher visibility for both anonymous and authenticated roles, region filtering, bounded results and teacher-school links.

Only implementation, tests and aggregate reports are published in GitHub. Personnel archives, cached pages, exact proofs, backups and staging SQL remain in ignored local storage. The public personnel catalog is published on the website only.
