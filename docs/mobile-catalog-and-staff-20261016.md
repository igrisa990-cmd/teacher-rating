# Mobile catalog, school-scoped search and staff expansion

The active site catalog contains **57,000 teachers across 2,149 schools**, within a catalog of **41,662 school profiles**. Import `20261016-staff-mobile` inserted **581 teachers from 26 additional schools**: 49 from current Word tables and 532 from freshly checked HTML rosters. The database reports 0 ambiguous names, 0 links to existing people, 0 unmatched schools and 0 orphan teacher-school associations. This remains an incomplete national teacher catalog.

## Mobile interface

The compact header has a logo/Home action, direct catalog search, account access and a menu with larger targets. Main sections remain available from the menu. Settings use larger cards with distinct SVG icons and color accents, plus four large color-mode buttons. Nested settings retain existing themes, region, account saving and dock preferences. Form fields use readable text sizes and the account dialog controls have at least 44px height. The modal layer sits above the sticky mobile header. The navigation dock hides while editing text, and returns when input focus leaves. No Auth, SMTP, SMS or account-role settings changed.

Mobile search exposes a visible Find button, larger filters, suggestions and profile controls. School results have separate «Учителя школы» and «О школе» actions. Selecting a school creates an explicit school filter; typing a surname or subject keeps that school selected. Changing/removing the school is separate from clearing the query. The global header search clears school scope. Empty states distinguish missing school staff from no matches to a query.

`search_school_teachers` is a bounded SECURITY INVOKER RPC. It filters by school UUID before matching, preserves caller RLS on both schools and teachers, excludes archived schools, supports normalized case/е/ё, word prefixes, subjects and a local spelling fallback. Results use stable ordering and 21-record pagination. The school foreign-key indexes already exist; no new personnel cache or privileged read helper was introduced. Global search behavior and RLS remain unchanged. Obsolete responses cannot overwrite newer input or a newly selected school.

## Source expansion

The legacy Word pass attempted 61 explicit same-origin document links and obtained 44. Apache POI HWPF 5.5.1 extracted bounded table structure from all 44 in read-only processes, without opening Office or running macros. Existing source hash, fresh organization identity, academic-year, explicit name/role/subject columns and current-license guards selected 49 teachers in 3 documents. The other 41 Word documents remain held for date review. Checksums of intermediate tables are validated, and private fields are excluded.

A standards-based parse5 fallback reads explicitly associated microdata and logical table grids, including declared row/column spans. It requires a full name and classroom-teacher role in the same explicit person block or logical table row. Qualification-category columns cannot stand in for a position; unrelated fields cannot borrow a role. Contact and private health fields are rejected. A cache audit identified 26 additional candidate schools; all were fetched again with public DNS, TLS, robots and current organization-identity checks. 23 yielded 532 teacher records. Three timed-out sites were retried once and remained unavailable; restrictions were not bypassed.

The full merged inventory retains all 23,603 school checkpoints and all established rosters with their original check times. Only unresolved, empty identity/format checkpoints can be overlaid. The prepared full snapshot has 56,964 eligible teachers across 2,148 schools; 36 earlier public profiles account for the site total. Only the 581 new records were staged. Install the pinned Java dependencies with `python scripts/install-legacy-word.py`, then run `python scripts/read-legacy-staff-doc.py --root work/staff-documents-20261016` using a JDK with `java` and `javac`. The installer and reader verify every JAR against `scripts/legacy-doc-lock.json`; XML output is separate from diagnostic logs. The Word reader has a 256 MB heap, a 20-second process timeout, and limits on file size, tables, rows, columns and text.
