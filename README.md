# Учитель+

Премиальная версия рейтинга школ и учителей.

## Supabase

Конфигурация находится только в `public/runtime-config.js`.
Не переносите service_role key в браузер.

Для базы выполните `supabase_schema_v6.sql` в Supabase SQL Editor.

## Архитектура

- школы и поиск по названию/городу/адресу
- рейтинг учителей внутри выбранной школы
- фильтры по предметам
- профили и отзывы
- регистрация/вход через Supabase Auth
- защита от повторной оценки через unique(teacher_id,user_id)
- автоматический пересчёт рейтинга триггером
- адаптивный premium UI
- demo fallback при временной недоступности Supabase

Vercel деплоит `public/index.html` автоматически из `main`.
