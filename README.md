# Учитель+

Современная платформа отзывов об учителях и школах. Интерфейс работает как одностраничное приложение и использует Supabase для каталога, авторизации и отзывов.

## Что есть в приложении

- поиск по учителям, предметам, школам, городам, адресам и регионам России;
- отдельный каталог 85 регионов и запоминаемый регион пользователя;
- фильтры и сортировка каталогов;
- подробные профили школ и преподавателей;
- сравнение до трёх преподавателей;
- избранное и личный кабинет ученика;
- отдельные оценки за объяснение, справедливость и атмосферу;
- отметки «полезно / не полезно» для отзывов;
- сообщество учеников без публикации личных данных;
- умный подбор преподавателя, случайная рекомендация и недавно просмотренные профили;
- прямые ссылки на профили и системная функция «Поделиться»;
- палитра быстрых действий по `Ctrl/Cmd + K`;
- светлая и тёмная темы, мобильная навигация и адаптивный интерфейс;
- регистрация и вход через Supabase Auth;
- народное добавление отсутствующих учителей: профиль публикуется после пяти независимых совпадающих заявок;
- отметка происхождения и статуса проверки данных школы или преподавателя.
- автоматическая проверка заявки по внутренней базе, официальной странице школы и подключаемому внешнему реестру;
- расширенная оценка по восьми критериям с шагом `0,1`;
- мобильная нижняя навигация, bottom-sheet формы и увеличенные зоны нажатия;
- раздел полезных материалов с отдельными страницами и контекстными карточками по сайту.
- регион выбирается при регистрации или в профиле и применяется к каталогам и чату;
- анонимный чат по регионам и общие комментарии в профиле школы;
- защита сообщества: стабильные псевдонимы, пауза между сообщениями, блокировка контактов и жалобы.
- мобильный UX v2: сворачиваемые фильтры, активная нижняя навигация, закреплённые действия, быстрые разделы и кнопка возврата наверх;
- контекстные подсказки на главной, в каталогах, профилях, регионах, чате и полезных материалах.
- единая строка поиска на каждом ключевом экране без повторяющихся полей;
- главная без верхнего рекламного заголовка: сохранены насущный вопрос, четыре основных перехода и блок полезных материалов;
- минимальный раздел учителей из двух действий: «Оцени учителя» и поисковое сравнение, плюс отдельное рекламное место;
- карточки действий в разделе учителей уменьшены, но сама промежуточная страница сохранена;
- «Оцени учителя» — единый поиск с разделёнными результатами по преподавателям и школам;
- из результата школы можно открыть её профиль или сразу найти преподавателей этой школы;
- умный подбор убран из основного потока и сохранён маленькой боковой кнопкой возле поиска;
- раздел школ начинается с выбора региона и только затем открывает отдельный каталог;
- чат региона оформлен как чистый анонимный мессенджер без справочных блоков;
- профиль учителя содержит только компактную карточку, три показателя статистики и отзывы учеников;
- профиль школы сохраняет статистику, отдельные оценки школы и директора, а также отзывы;
- мобильные профили используют компактные карточки статистики и последовательный поток без лишних вкладок;
- кнопки возврата используют реальную историю переходов внутри приложения;
- общая оценка вводится вручную с точностью `0,1`, быстрыми значениями и кнопками `− / +`;
- школы получили отдельную пользовательскую оценку с точностью `0,1`;
- директора школ получили отдельную оценку с точностью `0,1`, четырьмя критериями и собственными комментариями;
- статистика профилей показывает актуальные показатели доверия: оценку, отзывы, рекомендации, учителей и рейтинг директора;
- регистрация требует выбрать регион и сохраняет его в метаданных Supabase Auth;
- для разработки доступен быстрый демо-вход через отдельную анонимную Supabase-сессию;
- каталоги и служебные страницы разбиты на визуально отдельные смысловые сегменты;
- центрированная форма входа и регистрации с удобным отображением на телефонах;
- фирменная палитра «Ирис» дополнена переключаемыми вариантами «Океан», «Ягода» и «Графит», а также светлой и тёмной темами;
- добавлены цветные фоновые акценты, анимированное появление страниц и динамические подсветки карточек;
- стабильная мобильная панель из пяти маршрутов: главная, учителя, школы, чат и отдельная вкладка «Полезное».
- на мобильных устройствах зафиксирована ширина страницы и устранён горизонтальный сдвиг интерфейса.

## Запуск

```bash
npm install
npm run dev
```

Vercel публикует содержимое `public`. Клиентская конфигурация Supabase находится в `public/runtime-config.js`; ключ `service_role` нельзя размещать в браузере.

Для новой базы запустите `supabase_schema_v7.sql` в Supabase SQL Editor. Для уже созданной базы примените идемпотентные миграции по порядку:

- `supabase/migrations/20260917_expand_catalog.sql` — 6 школ и 18 преподавателей;
- `supabase/migrations/20260917_review_votes.sql` — оценки полезности отзывов.
- `supabase/migrations/20260918_russia_regions_and_requests.sql` — регионы, источники данных, обновление оценок и заявки на учителей с автоматической публикацией после 5 подтверждений.
- `supabase/migrations/20260919_verification_decimal_ratings.sql` — очередь проверок, статусы верификации, десятичные оценки и новые критерии.
- `supabase/migrations/20260919_mobile_regions_chat.sql` — шаг оценки 0,1, региональный чат, комментарии школ, антиспам и жалобы.
- `supabase/migrations/20260922_school_ratings.sql` — отдельные оценки школ, комментарий к оценке и политики доступа.
- `supabase/migrations/20260924_director_ratings.sql` — оценки директоров, четыре критерия и политики доступа.

### Демо-вход через Supabase

Текущий демо-режим создаёт отдельного анонимного пользователя для каждого браузера. Чтобы его включить:

1. Откройте проект в Supabase Dashboard.
2. Перейдите в `Authentication` → `Providers`.
3. Откройте провайдер `Anonymous` и включите `Allow anonymous sign-ins`.
4. Сохраните настройки и нажмите на сайте «Войти в демо-режим».

Тестовая пара `demo@teacherplus.test` / `Demo2026!` также направляет в этот анонимный режим: отдельного пользователя с таким email в Supabase создавать не нужно. Анонимная сессия получает обычный `auth.uid()` и поэтому работает с RLS-политиками оценок и отзывов. Для публичного запуска демо-кнопку лучше скрыть или ограничить CAPTCHA и rate limit.

## Наполнение российского каталога

Рекомендуемый конвейер: официальный реестр или региональный каталог школ → нормализация и устранение дублей → публичные разделы `Сведения об образовательной организации / Педагогический состав` → автоматические проверки → ручная модерация спорных записей → публикация. Для каждой записи сохраняются `source_url`, `source_type` и `verified_at`.

Импорт должен собирать только опубликованные профессиональные сведения. Личные телефоны, домашние адреса и другие частные данные в каталог не загружаются. Условия использования, `robots.txt`, частота запросов и правовые основания проверяются отдельно для каждого источника.

## Автоматическая проверка учителя

После миграции разверните Edge Function:

```bash
supabase functions deploy verify-teacher
```

Функция из `supabase/functions/verify-teacher/index.ts` использует четыре исхода:

1. точное совпадение во внутренней базе — немедленное подтверждение;
2. совпадение ФИО и предмета на уже подтверждённой официальной странице школы;
3. внешний реестр, если настроены secrets `TEACHER_REGISTRY_ENDPOINT` и `TEACHER_REGISTRY_TOKEN`;
4. `needs_review`, если цифровых доказательств недостаточно. Недоступный сайт сам по себе не приводит к отказу.

Пять совпадающих заявок разных пользователей сохранены как резервное подтверждение для небольших населённых пунктов без сайта и внешних записей.
